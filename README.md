# FUTURE_CS_03 – API Security Risk Analysis

## Project Overview

This repository contains the deliverables for **Task 3 – API Security Risk Analysis**, completed as part of the **Future Interns Cyber Security Internship**. The project focused on assessing the security of publicly available REST APIs by analyzing API endpoints, request and response headers, authentication mechanisms, input validation, and potential security risks. The assessment was performed using safe and non-intrusive techniques to identify common API security issues and recommend appropriate mitigation measures.

---

## Objectives

- Analyze publicly accessible API endpoints.
- Examine API requests and responses.
- Evaluate authentication and authorization mechanisms.
- Identify insecure API configurations and data exposure risks.
- Review request and response headers.
- Assess input validation and endpoint security.
- Classify identified risks based on their severity.
- Recommend security best practices and remediation measures.
